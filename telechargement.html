Launcher Draco

Télécharger le jeu

Le launcher contient le client Dofus Retro déjà configuré pour Draco. Il gère tes comptes et lance le jeu en un clic.

Installation

  1. Télécharge l'archive .zip puis fais clic droit → Extraire tout…
  2. Ouvre le dossier et double-clique sur Draco.
  3. Dans le launcher : « J'ai déjà un compte » (ou crée-le directement), puis JOUER.

Windows peut afficher « Windows a protégé votre ordinateur » : clique sur Informations complémentaires puis Exécuter quand même.

💻 Configuration

Windows 10 ou 11, 64 bits. 2 Go de RAM, 1 Go d'espace disque.

👥 Multi-comptes

Coche plusieurs comptes dans le launcher : un client s'ouvre pour chacun.

📝 Pas encore de compte ?

Crée-le ici ou directement depuis le launcher.
